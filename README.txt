مدیر تیم - نسخه آزمایشی محلی

مهم:
همه فایل‌های این پوشه باید کنار START.bat باشند.

ساختار صحیح:
START.bat
requirements.txt
README.txt
app\main.py
app\db.py (ممکن است در این نسخه وجود نداشته باشد)
web\index.html
data\

اجرا:
1. کل ZIP را Extract کنید.
2. وارد همان پوشه‌ای شوید که START.bat و requirements.txt هر دو در آن هستند.
3. روی START.bat دوبار کلیک کنید.
4. مرورگر روی http://127.0.0.1:8000 باز می‌شود.

اگر Python نصب نیست، Python 3.11+ نصب کنید و هنگام نصب
گزینه Add Python to PATH را فعال کنید.
